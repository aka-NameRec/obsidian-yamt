# Feature: Column Alignment (colalign)

**Дата:** 2025-11-11  
**Автор:** aka.NameRec@gmail.com  
**Статус:** ✅ Реализовано

## Суть предложения

Добавить возможность управления выравниванием целых колонок таблицы через атрибут `colalign` в ячейках заголовка, чтобы избежать дублирования атрибута `align` для каждой ячейки body.

## Мотивация

При создании таблиц с однородным выравниванием колонок (например, числовые данные справа, текст слева) приходилось повторять атрибут `align` для каждой ячейки body. Это приводило к избыточности кода и усложняло поддержку.

**До:**
```yaml
body:
  - [ "Product A", { data: "1299", align: right } ]
  - [ "Product B", { data: "899", align: right } ]
  - [ "Product C", { data: "42", align: right } ]
```

**После:**
```yaml
header:
  - [ "Name", { data: "Price", colalign: right } ]
body:
  - [ "Product A", "1299" ]  # Автоматически вправо
  - [ "Product B", "899" ]
  - [ "Product C", "42" ]
```

## Реализованная функциональность

### 1. Базовый атрибут `colalign`

Добавлен новый атрибут `colalign` в ячейках заголовка, который определяет выравнивание для всей колонки:

```yaml
header:
  - [ 
      { data: "Name", colalign: left },
      { data: "Price", colalign: right },
      { data: "Status", colalign: center }
    ]
```

### 2. Влияние на саму ячейку заголовка

`colalign` влияет не только на колонку в body, но и на саму ячейку заголовка (если нет явного `align`):

```yaml
{ data: "Price", colalign: right }  # "Price" выровнен вправо
```

### 3. Наследование в многострочных заголовках

Ячейки заголовка наследуют `colalign` из предыдущих строк заголовка:

```yaml
header:
  - [ { data: "Product", colspan: 2 }, { data: "Price", colalign: right } ]
  - [ "Category", "Name", { data: "€" } ]  # "€" наследует right от "Price"
```

### 4. Поддержка rowspan/colspan

Правильная обработка сложных заголовков с `rowspan` и `colspan`:

```yaml
header:
  - [ 
      { data: "ID", rowspan: 2, colalign: center },
      { data: "Product Info", colspan: 2, colalign: left },
      { data: "Metrics", colspan: 2, colalign: right }
    ]
  - [ 
      { data: "Category" },  # Колонка 1: наследует left
      { data: "Name" },      # Колонка 2: наследует left
      { data: "Price" },     # Колонка 3: наследует right
      { data: "Stock" }      # Колонка 4: наследует right
    ]
```

### 5. Приоритет атрибутов

Для любой ячейки (заголовка или body):
1. **`align`** — наивысший приоритет (явное указание)
2. **`colalign`** — используется если нет `align`
3. **Наследование** — из предыдущих строк заголовка (для header) или из заголовка (для body)
4. **Browser default** — если ничего не указано

### 6. Ключевые отличия align vs colalign

| Атрибут | Область влияния | Наследование |
|---------|----------------|--------------|
| `align` | Только эта ячейка | ❌ Нет |
| `colalign` | Эта ячейка + вся колонка | ✅ Да |

## Технические детали

### Изменения в коде

**1. Типы данных (`src/lib.ts`):**
```typescript
export interface NormalizedCell {
  data: string;
  align?: Align;
  colalign?: Align;  // ← Новый атрибут
  // ... остальные поля
}
```

**2. Построчная обработка заголовка (`src/main.ts`):**

Добавлена функция `renderHeaderRows()`, которая:
- Обрабатывает строки заголовка последовательно
- Накапливает `columnAlignments` по мере обработки
- Правильно учитывает `rowspan` для отслеживания занятых колонок
- Возвращает финальный массив выравниваний для body

**3. Применение выравнивания (`src/main.ts`):**

Функция `renderRow()` обновлена:
- Принимает `columnAlignments` и `occupiedColumns`
- Пропускает занятые колонки при определении текущего индекса
- Применяет выравнивание с правильным приоритетом

### Алгоритм работы

```
Для каждой строки заголовка (по порядку):
  1. Рендерим строку с текущим columnAlignments
  2. При рендеринге каждой ячейки:
     - Пропускаем занятые колонки (rowspan из предыдущих строк)
     - Применяем: cell.align || cell.colalign || columnAlignments[colIndex]
  3. После рендеринга обновляем columnAlignments:
     - Если ячейка имеет colalign, сохраняем его для соответствующих колонок
     - Учитываем colspan (применяем ко всем охваченным колонкам)
     - Отмечаем занятые колонки для rowspan > 1

Для body:
  Рендерим с финальным columnAlignments из заголовка
```

## История разработки

В процессе реализации были выявлены и исправлены следующие проблемы:

1. **Начальная версия**: `colalign` не влиял на саму ячейку заголовка
2. **Исправление**: добавлено применение к ячейке заголовка с правильным приоритетом
3. **Проблема с наследованием**: ячейки последующих строк заголовка не наследовали `colalign`
4. **Исправление**: реализована построчная обработка с накоплением `columnAlignments`
5. **Проблема с rowspan**: неправильное сопоставление индексов колонок
6. **Исправление**: добавлено отслеживание занятых колонок в `renderRow`
