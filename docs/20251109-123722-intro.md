💡 1. Можно ли **отрендерить таблицу Word/Writer или Excel/Calc** в Obsidian?

### 🧩 Короткий ответ

_Напрямую — нет_, но можно **автоматизировать преобразование** в Markdown-совместимый формат.  
Есть несколько надёжных подходов:

| Способ | Описание | Уровень боли 😅 |
| --- | --- | --- |
| **Pandoc** | Преобразует `.docx` или `.xlsx` → `.md` с таблицами. Пример: `pandoc table.xlsx -o table.md` | 🔹 Средний — но качество рендеринга выше стандартного Markdown |
| **CSV + Obsidian Table Editor / Dataview** | Экспортируешь из Excel/Writer таблицу в CSV → подключаешь DataView (`TABLE ... FROM "..."`) | 🔹 Минимальный — DataView хорошо работает с CSV |
| **Embedded View (Markdown Embed)** | Создаёшь рядом `.csv` или `.md` файл и вставляешь `![[table.csv]]` или `![[table.md]]` | 🔹 Простой, но ограниченный вариант |
| **Excel Viewer Plugin** | Плагин для Obsidian, открывающий `.xlsx` прямо в ноте (см. ниже) | 🔹 Работает, но не редактируемо, только просмотр |

📦 **Попробуй плагины:**

*   [`Advanced Tables`](https://github.com/tgrosinger/advanced-tables-obsidian) — упрощает ручное редактирование Markdown-таблиц.
*   `Excel to Markdown Table` — позволяет прямо в Obsidian вставить содержимое таблицы Excel как Markdown.
*   `CSV Table` — открывает CSV как красивую таблицу.

⚙️ 2. Что умеет **DataView** и можно ли с его помощью делать сложные заголовки?
-------------------------------------------------------------------------------

DataView — мощный инструмент, но **вёрстка таблиц у него ограничена**, т.к. движок не HTML, а собственный.  
Вот что он умеет / не умеет:

| Возможность | Поддержка |
| --- | --- |
| Отключить заголовки (т.е. просто колонки без шапки) | ❌ Нет (всегда рендерит `<thead>`) |
| Составные заголовки (multi-row) | ❌ Нет |
| Форматирование содержимого (жирный, цвет, иконки и т.п.) | ⚠ Частично (через inline Markdown или DataviewJS) |
| Гибкое форматирование ячеек | ✅ Да, **через DataviewJS**, если готов писать JS |
| Слияние ячеек (`colspan`/`rowspan`) | ❌ Нет |

👉 **Что можно сделать:**

*   использовать **`DataviewJS`** и через `dv.table()` вручную собрать структуру с нужными стилями;
*   либо — комбинировать DataViewJS с **Templater**, генерируя HTML вручную (но тогда ты теряешь смысловую чистоту markdown).

📘 Пример DataViewJS с кастомным форматированием:

```dataviewjs
dv.table(["Название", "Прогресс", "Состояние"], [
  ["Модуль 1", "✅", "**Готово**"],
  ["Модуль 2", "🔄", "<span style='color:orange'>В процессе</span>"],
])
```

🧱 3. Есть ли **другие инструменты / плагины** для сложных таблиц (в т.ч. PDF)?
-------------------------------------------------------------------------------

Да, и это, пожалуй, самый интересный пункт — потому что сегодня реально есть **три устойчивых ветки развития таблиц в Obsidian**:

| Подход | Что делает | Ключевые плагины / инструменты |
| --- | --- | --- |
| **Markdown++** | Расширяет синтаксис Markdown (в т.ч. таблицы с colspan/rowspan, выравниванием, стилями) | Obsidian Markdown Table Editor (ещё экспериментален) |
| **Markdown + HTML гибрид** | Можно писать `<table>` прямо в Markdown и вставлять `<td markdown="1">` для inline форматирования | Родной движок Obsidian (работает, если не мешает плагин Table Extended) |
| **Pandoc Export → PDF** | Pandoc поддерживает LaTeX-таблицы, многоуровневые заголовки, стили и даже auto-fit | Комбо: `pandoc -s input.md -o output.pdf --pdf-engine=xelatex` |
| **Mermaid / Markdown Canvas / DataviewJS Hybrid** | Не таблица, а визуальное представление связей / сеток | Для специфичных задач, например проектных дашбордов |

✅ Итого — рекомендую такую **практическую схему**
-------------------------------------------------

| Задача | Лучшее решение | Комментарий |
| --- | --- | --- |
| Таблица «для глаз» (быстрое редактирование в ноте) | `Advanced Tables` + `Table Editor` | Нормально форматируется, редактируется в Obsidian |

| Составные заголовки | Только через `HTML` или Pandoc / LaTeX | Markdown не умеет сам по себе |

🔮 Мини-рецепт: гибрид Markdown + HTML для Obsidian
---------------------------------------------------

Пример, где таблица остаётся "markdown-понятной", но поддерживает colspan, markdown-разметку и экспорт в PDF:

```html
<table>
  <thead>
    <tr>
      <th colspan="2">📦 Продукт</th>
      <th>Цена</th>
    </tr>
    <tr>
      <th>Категория</th>
      <th>Название</th>
      <th>€</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td markdown="1">**Техника**</td>
      <td markdown="1">`Ноутбук Dell XPS`</td>
      <td>1299</td>
    </tr>
  </tbody>
</table>
```

Obsidian корректно это рендерит, PDF-экспорт через Pandoc — тоже.

### 🔸 Рендеринг
Парсинг YAML → HTML `<table>` с поддержкой:

- `colspan`, `rowspan`
- `align` (`left`, `right`, `center`)
- `bg` / `color`
- markdown-рендер внутри ячеек
- глобальные стили (по умолчанию совпадающие с Obsidian-темой)

### 🔸 Реализация
- Frontend на TypeScript (используя `markdownPostProcessor`)
- YAML-парсер: [`js-yaml`](https://github.com/nodeca/js-yaml)
- Markdown-рендер: `MarkdownRenderer.renderMarkdown(...)` — нативный API Obsidian
- Опционально: реактивный перерендер при изменении блока

### 🔸 Мини-пример рендерера
(чтобы ты понимал, насколько это реально просто)

```ts
import { MarkdownPostProcessorContext, MarkdownRenderer } from "obsidian";
import yaml from "js-yaml";

async function renderYAMT(source: string, el: HTMLElement, ctx: MarkdownPostProcessorContext) {
  const data = yaml.load(source);
  const table = el.createEl("table");

  for (const section of data) {
    const sectionEl = table.createEl(section.header ? "thead" : "tbody");
    for (const row of section.row ?? []) {
      const tr = sectionEl.createEl("tr");
      for (const cell of row.cell ?? []) {
        const td = tr.createEl(section.header ? "th" : "td");
        if (cell.align) td.style.textAlign = cell.align;
        if (cell.bg) td.style.backgroundColor = cell.bg;
        if (cell.color) td.style.color = cell.color;
        await MarkdownRenderer.renderMarkdown(cell.data ?? "", td, ctx.sourcePath, ctx);
      }
    }
  }
}
````

Подключаешь этот постпроцессор к коду:

```ts
this.registerMarkdownCodeBlockProcessor("yamt", renderYAMT);
```

— и всё: YAML-таблицы начинают рендериться.

}

} from "obsidian";
import yaml from "js-yaml";

/** Пользовательская схема (гибкая):
 *
 *  1) Рекомендуемый формат:
 *  header:  # необязательно
 *    - [ cell, cell, ... ]
 *    - [ ... ]
 *  body:
 *    - [ ... ]
 *
 *  2) Ячейка может быть:
 *    - строкой -> { data: строка }
 *    - объектом -> { data, align, color, bg, colspan, rowspan }
 *    - обёрткой -> { cell: { ...как выше... } }
 *
 *  3) Синонимы:
 *    colspan: number | "2"
 *    rowspan: number | "2"
 *    align: "left"|"center"|"right"
 *    color/bg: CSS-значения (на твой риск)
 *    hts_colspan / hts_rowspan тоже понимаем (дружим с твоим черновиком 😉)
 */

type RawCell =
  | string
  | {
      cell?:
        | string
        | {
            data?: string;
            align?: "left" | "center" | "right";
            color?: string;
            bg?: string;
            colspan?: number | string;
            rowspan?: number | string;
            /** синонимы */
            hts_colspan?: number | string;
            hts_rowspan?: number | string;
          };
      data?: string;
      align?: "left" | "center" | "right";
      color?: string;
      bg?: string;
      colspan?: number | string;
      rowspan?: number | string;
      hts_colspan?: number | string;
      hts_rowspan?: number | string;
    };

type Row = RawCell[];

/** Основная структура */
interface YamtDocLike {
  header?: Row[];
  body?: Row[];
}

export default class YamtPlugin extends Plugin {
  async onload() {
    this.registerMarkdownCodeBlockProcessor(
      "yamt",
      async (source, el, ctx) => {
        try {
          const doc = parseYamlAny(source);
          const model = normalizeToModel(doc);

          if (!model.header?.length && !model.body?.length) {
            throw new YamtValidationError(
              [
                "Не удалось обнаружить ни одной строки таблицы.",
                "Ожидаемый формат:",
                "",
                "header:",
                "  - [ { data: \"…\" }, { data: \"…\" } ]",
                "body:",
                "  - [ \"строка как data\", { data: \"**md**\", align: right } ]",
              ].join("\n")
            );
          }

          const table = el.createEl("table", { cls: "yamt-table" });

          if (model.header?.length) {
            const thead = table.createEl("thead");
            for (const row of model.header) {
              await renderRow(thead, row, true, ctx);
            }
          }

          if (model.body?.length) {
            const tbody = table.createEl("tbody");
            for (const row of model.body) {
              await renderRow(tbody, row, false, ctx);
            }
          }
        } catch (e: any) {
          renderYamlError(el, e);
        }
      }
    );
  }
}

/** === helpers === */

function parseYamlAny(source: string): unknown {
  try {
    return yaml.load(source);
  } catch (e: any) {
    // js-yaml даёт e.mark с (line, column)
    const loc = e?.mark
      ? `строка ${e.mark.line + 1}, столбец ${e.mark.column + 1}`
      : null;
    const msg = e?.message ?? "Неизвестная ошибка разбора YAML.";
    const hint = loc ? `${msg} (${loc})` : msg;

    const err = new YamtYamlError(hint);
    (err as any).inner = e;
    throw err;
  }
}

function normalizeToModel(doc: unknown): YamtDocLike {
  // Наиболее дружелюбный режим:
  // - если это объект с header/body -> берём их
  // - если это массив секций -> пробуем понять
  if (isRecord(doc)) {
    const header = maybeNormalizeRows((doc as any).header);
    const body = maybeNormalizeRows((doc as any).body);
    if (header || body) return { header: header ?? [], body: body ?? [] };
  }

  if (Array.isArray(doc)) {
    // допускаем массив секций вида:
    // [ { header: [...] }, { body: [...] } ] или [ { type:'header', rows:[...] }, ... ]
    let header: Row[] = [];
    let body: Row[] = [];

    for (const section of doc as any[]) {
      if (!isRecord(section)) continue;

      // секция 1: { header: [...] }
      if (section.header) {
        header = maybeNormalizeRows(section.header) ?? header;
      }
      if (section.body) {
        body = maybeNormalizeRows(section.body) ?? body;
      }

      // секция 2: { type:'header'|'body', rows:[...] }
      if (typeof section.type === "string" && section.rows) {
        const rows = maybeNormalizeRows(section.rows) ?? [];
        if (section.type === "header") header = rows;
        if (section.type === "body") body = rows;
      }
    }

    if (header.length || body.length) return { header, body };
  }

  // Если прилетел просто массив строк/ячеек — считаем это body одной строкой
  if (Array.isArray(doc)) {
    const asRow = normalizeRow(doc as RawCell[]);
    return { body: [asRow] };
  }

  throw new YamtValidationError(
    [
      "Неверная структура YAML для YAMT.",
      "Ожидается объект с ключами `header`/`body` или массив секций.",
      "Пример:",
      "",
      "header:",
      "  - [ { data: \"📦 Продукт\", colspan: 2 }, { data: \"Цена\" } ]",
      "  - [ { data: \"Категория\" }, { data: \"Название\" }, { data: \"€\", align: right } ]",
      "body:",
      "  - [ \"**Техника**\", \"`Ноутбук Dell XPS`\", { data: \"1299\", align: right } ]"
    ].join("\n")
  );
}

function maybeNormalizeRows(rows: unknown): Row[] | undefined {
  if (!rows) return undefined;
  if (!Array.isArray(rows)) return undefined;

  // допускаем:
  // - список массивов (каждый массив — ряд)
  // - список объектов вида { row: [...] }
  const result: Row[] = [];
  for (const r of rows) {
    if (Array.isArray(r)) {
      result.push(normalizeRow(r));
      continue;
    }
    if (isRecord(r) && Array.isArray((r as any).row)) {
      result.push(normalizeRow((r as any).row));
      continue;
    }
    // также допускаем единичные ячейки (будут обёрнуты в строку)
    result.push(normalizeRow([r as RawCell]));
  }
  return result;
}

function normalizeRow(cells: RawCell[]): Row {
  return cells.map(normalizeCell);
}

function normalizeCell(cell: RawCell): RawCell {
  // строка -> { data: "…" }
  if (typeof cell === "string") return { data: cell };

  if (isRecord(cell)) {
    // обёртка { cell: {...} } или { cell: "…" }
    if ("cell" in cell) {
      const inner = (cell as any).cell;
      if (typeof inner === "string") return { data: inner };
      if (isRecord(inner)) return normalizeCellObject(inner);
    }
    return normalizeCellObject(cell as Record<string, any>);
  }

  return { data: String(cell ?? "") };
}

function normalizeCellObject(obj: Record<string, any>): any {
  const out: Record<string, any> = {};
  if (obj.data != null) out.data = String(obj.data);

  // синонимы colspan/rowspan
  const colspan = obj.colspan ?? obj.hts_colspan ?? obj.span;
  const rowspan = obj.rowspan ?? obj.hts_rowspan;

  if (colspan != null) out.colspan = toInt(colspan);
  if (rowspan != null) out.rowspan = toInt(rowspan);

  // выравнивание
  if (obj.align && ["left", "center", "right"].includes(obj.align)) {
    out.align = obj.align;
  }

  if (obj.color) out.color = String(obj.color);
  if (obj.bg) out.bg = String(obj.bg);

  // если data не задано — допустим пустую строку
  if (out.data == null) out.data = "";
  return out;
}

function toInt(v: unknown): number | undefined {
  const n = Number(v);
  if (Number.isFinite(n) && n >= 1) return Math.floor(n);
  return undefined;
}

async function renderRow(
  parent: HTMLElement,
  row: Row,
  isHeader: boolean,
  ctx: MarkdownPostProcessorContext
) {
  const tr = parent.createEl("tr");
  for (const rawCell of row) {
    const cell = normalizeCell(rawCell);
    const el = tr.createEl(isHeader ? "th" : "td");

    // применяем атрибуты
    const colSpan = (cell as any).colspan as number | undefined;
    const rowSpan = (cell as any).rowspan as number | undefined;
    if (colSpan && colSpan > 1) el.setAttr("colspan", String(colSpan));
    if (rowSpan && rowSpan > 1) el.setAttr("rowspan", String(rowSpan));

    const align = (cell as any).align as
      | "left"
      | "center"
      | "right"
      | undefined;
    if (align) el.style.textAlign = align;

    const color = (cell as any).color as string | undefined;
    const bg = (cell as any).bg as string | undefined;
    if (color) el.style.color = color;
    if (bg) el.style.backgroundColor = bg;

    // Markdown внутри ячейки
    const data = (cell as any).data ?? "";
    // делаем контейнер для корректного markdown-rendering
    const inner = el.createDiv();
    await MarkdownRenderer.renderMarkdown(
      String(data),
      inner,
      ctx.sourcePath,
      ctx
    );
  }
}

/** === Ошибки и вывод === */

class YamtYamlError extends Error {
  name = "YAMT/YamlError";
}
class YamtValidationError extends Error {
  name = "YAMT/ValidationError";
}

function renderYamlError(container: HTMLElement, e: any) {
  const wrap = container.createDiv({ cls: "yamt-error" });

  const title = document.createElement("div");
  title.innerHTML = `<strong>YAMT: ошибка разбора/валидации YAML</strong>`;
  wrap.appendChild(title);

  const lines: string[] = [];

  if (e instanceof YamtYamlError || e instanceof YamtValidationError) {
    lines.push(String(e.message ?? "Неизвестная ошибка."));
  } else if (e && e.message) {
    lines.push(String(e.message));
  } else {
    lines.push("Неизвестная ошибка.");
  }

  // если js-yaml дал .mark — добавим её (js-yaml мы уже завернули, но вдруг)
  const mark = (e?.inner && e.inner.mark) || e?.mark;
  if (mark && Number.isFinite(mark.line) && Number.isFinite(mark.column)) {
    lines.push(`Место: строка ${mark.line + 1}, столбец ${mark.column + 1}`);
  }

  // подсказка по схеме
  if (e instanceof YamtValidationError) {
    lines.push("");
    lines.push("Справка по формату см. README или пример ниже.");
  }

  wrap.appendChild(document.createElement("pre")).textContent = lines.join("\n");
}

/** utils */
function isRecord(v: unknown): v is Record<string, unknown> {
  return typeof v === "object" && v !== null;
}

# YAMT (Yet Another Markdown Table)

Рендер таблиц из YAML в Obsidian.

## Использование

Вставьте блок:

```yamt
header:
  - [ { data: "📦 Продукт", colspan: 2 }, { data: "Цена" } ]
  - [ { data: "Категория" }, { data: "Название" }, { data: "€", align: right } ]
body:
  - [ "**Техника**", "`Ноутбук Dell XPS`", { data: "1299", align: right } ]
````

Поддержка:

*   `colspan`, `rowspan` (синонимы: `hts_colspan`, `hts_rowspan`, `span`)
*   `align: left|center|right`
*   `bg`, `color` (CSS-значения)
*   Markdown внутри ячеек

Альтернативная форма ячеек
--------------------------

```yaml
body:
  - 
    - cell: { data: "**bold**", color: "#0aa" }
    - cell: "`inline code`"
```

Диагностика
-----------

Ошибки YAML показываются с указанием строки/столбца (если возможно) и с подсказками по валидной схеме.
